Part calendar. Part workbook. All theirs.

The first page tells kids exactly how to use it. Here's the short version.

  1. Color-code your days. Pick a color for each home so the week makes sense at a glance.
  2. Add the fun things. Yes days, sleepovers, field trips. Write them in or use the stickers.
  3. Don't forget the important stuff. Haircuts, doctor visits, project due dates.
  4. Use the tools pages when feelings get big.
  5. Have fun. Plans change and mistakes happen. That's OK.
